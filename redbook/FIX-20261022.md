# Fork 修改记录 — CDP Cookie 提取修复（基于官方测试的修改）

- 基线：`@lucasygu/redbook@0.8.2`（npm registry 官方 tarball，未改前的原版）
- 日期：2026-10-22
- 平台：Windows 10 + Chrome 155.0.8059.84（CDP 调试端口 9222）

## 问题（测试发现）

官方 CLI 在新版 Chrome 上 CDP cookie 提取完全失效：

```
Requesting all cookies via CDP (Network.getAllCookies)...
CDP cookie extraction failed: CDP error: 'Network.getAllCookies' wasn't found
Error: No 'a1' cookie found for xiaohongshu.com in chrome.
```

根因：Chrome 132 弃用 `Network.getAllCookies`，Chrome 155 彻底移除；官方代码
（`dist/lib/cdp-cookies.js` 第 98 行）仍调用该 API。

## 修改（dist/lib/cdp-cookies.js）

`getCookiesFromCdp()`：优先调用替代 API **`Storage.getCookies`**（浏览器级 cookie 存储，
返回字段与旧 API 相同）；若报 "method not found" 则自动降级尝试旧 API
`Network.getAllCookies`（兼容旧版 Chrome）。同步更新 `.d.ts` 注释与日志文案。
